# 共生的差异 / Symbiosis — v4

纯画面的交互艺术作品。页面只保留「演示、全屏、重置、交互模式」四个控件。主画面不显示标题、正文、导航、数值面板与进度文字。点击「交互模式」可打开操作说明及共生理念面板；阅读时场域暂停，关闭后继续。点、细线、透明色面与碎裂符号构成画面。

## 三个素材库

| 场域 | 大陆 / 广东 | 澳门 | 总数 |
|---|---:|---:|---:|
| 交通图形 | 50 | 50 | 100 |
| 繁简汉字 | 50 简体字 | 50 繁体字 | 100 |
| 文化纹样 | 20 | 20 | 40 |

共 240 个独立 SVG，主页面内嵌，无需网络加载。每个素材在场域内只出现一次；没有用克隆、修改限速数字或随机换色扩充数量。100 个交通图形分别编写路径，拥有不同的语义与构形。100 个汉字来自 50 组繁简字，全部字符不重复。40 个文化纹样分别编写结构，并使用不同的主色、辅色组合。

- `asset-atlas.html`：可离线打开的完整素材索引，查看所有编号、名称、图形。
- `assets/`：240 个可编辑 SVG 原稿，按类别和地域语境分目录。
- `assets-manifest.json`：素材数据与 SVG 源码。
- `validation.json`：数量、ID、SVG 文档及汉字唯一性校验。

## 交互

- **交互模式**：查看操作说明与共生理念；支持「开始探索」、关闭按钮、Esc 和点击面板外部关闭。

- **移动鼠标 / 单指拖动**：扭转三维空间，改变疏密、纵深和引力；靠近图形时产生局部扰动。
- **长按**：两族符号沿相反方向被吸入指尖附近的漩涡；约 1.45 秒蓄满。
- **松开**：释放冲击，打散符号后逐步重组。
- **轻点**：在画面中留下一个折点和细线，改变局部的视觉构成。
- **滚轮 / 触控板纵向滑动**：切换交通、汉字、文化纹样三个场域。
- **双击**：切换到下一场域。
- **双指横向滑动**：切换场域，单指仍用于空间交互。
- **配对**：靠近图形上带有短弧的两个光核，各触碰一个即完成一对。三对之后，240 个独立素材共同进入约 11 秒的共生形态，之后转入下一场域。仅用点、短线和涟漪反馈，无文字计分。
- **演示**：自动探索、配对、蓄力和释放，并切换场域。主动操作退出演示。
- **键盘**：Tab 选择控制按钮；画布聚焦时，方向键移动光标；空格按住蓄力、松开释放；1、2、3 切换场域；F 全屏；R 重置。

同一符号的不同切片只构成该符号的破碎图像，不是重复实例。共生形态不替换图案、不统一字形，保留每个素材的身份。

## 艺术与文化取样

**交通**：大陆组提取道路功能、交叉、禁令、慢行、公共交通和城市设施；澳门组提取中葡街牌、左侧交通语境、坡巷、石仔路、轻轨、巴士港湾、跨海桥与水陆接驳等城市线索。它们是 100 件原创图形研究，不声称对应 100 个互不相同的官方交通规定，也不声称通用符号只存在于某一地。画面刻意拆开容器、线条与空间，使之不再成为完整的实用路牌。

**汉字**：50 组字形对照，字符不重复。繁体采用衬线字形，简体采用无衬线字形。断行、横向错位、尺度变化保留字形辨识与解读空间。

**文化**：广东组从木棉、广绣、广彩、醒狮、龙舟、荔枝、满洲窗、灰塑、佛山剪纸、香云纱、潮绣、云肩、石湾陶涡、端砚、竹编、缠枝莲、鳞波、粤剧水袖、客家围屋与铜凿团花中提取结构；澳门组从瓷砖几何、四瓣花、卷草、航海纹、贝壳、莲花、波纹、绳结、花叶及石仔路结构中发展 20 个图案。两组均为重新绘制的艺术设计，不冒充具体馆藏、族群的专属图腾或经考证的古纹样原件。

## 使用与部署

解压后双击 `index.html`。主作品无需构建、安装、密钥、网络字体或图片服务。当前浏览器默认字体决定汉字细节。

上传整个目录到 GitHub 仓库根目录，在 **Settings → Pages → Deploy from a branch** 选择你的分支和 **/ (root)**。主页面为 `index.html`；`.nojekyll` 已包含。子路径部署可用。

支持近期版本 Chrome、Safari、Edge、Firefox。全屏以浏览器支持为准。系统偏好减少动态时会降低运动速度；切到后台暂停渲染、取消按住状态并退出演示。
